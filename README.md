# The Analysis
The following analyses explore salary trends, job demand, and the technical skills that shape the data analyst job market:

### 1. Top Paying Data Analysis Jobs
To identify the highest-paying Data Analyst roles, I filtered job postings based on average yearly salary, job title, and location, with a focus on remote positions. This analysis highlights the highest-paying opportunities in the data analytics job market.

```sql
SELECT
    job_id,
    job_title,
    job_location,
    job_schedule_type,
    salary_year_avg,
    job_posted_date,
    name AS company_name
FROM
    job_postings_fact
LEFT JOIN company_dim ON job_postings_fact.company_id = company_dim.company_id
WHERE
    job_title_short = 'Data Analyst' AND
    job_location = 'Anywhere' AND
    salary_year_avg IS NOT NULL
ORDER BY 
    salary_year_avg DESC
LIMIT 10;
```

**Insights:**

**Highest Paying Opportunity**

* The highest-paying Data Analyst role is at **Mantys**, offering an annual salary of **$650,000**, making it a clear outlier among all job postings.

**Experience Drives Higher Salaries**

* Director and Principal-level positions dominate the list, showing that seniority and leadership responsibilities are associated with significantly higher salaries.

**Remote Roles Offer Competitive Pay**

* All of the top 10 highest-paying positions are **remote** and **full-time**, indicating that remote work opportunities can provide excellent earning potential in data analytics.

### 2. Skills Required for the Highest-Paying Job

The highest-paying data analyst role (**Associate Director – Data Insights**) requires a well-rounded technical skill set rather than a single specialization. The job combines:

* **Programming:** SQL, Python, R
* **Cloud Platforms:** AWS, Azure
* **Big Data:** PySpark, Databricks
* **Data Analysis:** Pandas, Jupyter
* **Business Tool:** Excel

```sql 
WITH top_paying_jobs AS (
    SELECT
    job_id,
    job_title,
    salary_year_avg,
    name AS company_name
    FROM
    job_postings_fact
    LEFT JOIN company_dim ON job_postings_fact.company_id = company_dim.company_id
    WHERE
    job_title_short = 'Data Analyst' AND
    job_location = 'Anywhere' AND
    salary_year_avg IS NOT NULL
    ORDER BY 
    salary_year_avg DESC
    LIMIT 10
)

SELECT 
    top_paying_jobs.*,
    skills
FROM top_paying_jobs
INNER JOIN skills_job_dim ON top_paying_jobs.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
ORDER BY 
    salary_year_avg DESC;
```

**Insight:** High-paying senior roles expect candidates to combine analytics, cloud computing, and big data technologies.

### 3: Most In-Demand Skills

The most frequently requested skills across data analyst job postings are:

* **SQL (92,628 postings)** – The most essential skill for data querying and database management.
* **Excel (67,031 postings)** – Continues to be a core business analytics tool.
* **Python (57,326 postings)** – Increasingly important for data analysis and automation.
* **Tableau (46,554 postings)** and **Power BI (39,468 postings)** – Leading visualization tools required by employers.

```sql
SELECT 
    skills,
    COUNT(skills_job_dim.job_id) AS demand_count
FROM job_postings_fact
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE  
    job_title_short = 'Data Analyst'
GROUP BY   
    skills
ORDER BY
    demand_count DESC
LIMIT 5;
```

**Insight:** SQL remains the foundation of data analytics, while Python and BI tools have become standard requirements for modern analyst roles.



### 4: Highest-Paying Skills

The highest average salaries are associated with specialized technologies such as:

* **PySpark ($208K)** and **Databricks** for big data processing.
* **Pandas, NumPy, and Jupyter** from the Python analytics ecosystem.
* **GitLab, Kubernetes, Linux, and Airflow**, highlighting the growing value of engineering and DevOps knowledge.

```sql
SELECT 
    skills,
    ROUND(AVG(salary_year_avg), 0) AS avg_salary
FROM job_postings_fact
INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE  
    job_title_short = 'Data Analyst' 
    AND salary_year_avg IS NOT NULL
    AND job_work_from_home = TRUE
GROUP BY   
    skills
ORDER BY
    avg_salary DESC
LIMIT 25;
```

**Insight:** Specialized skills in big data, cloud platforms, and data engineering command significantly higher salaries than traditional analytics tools.



### 5: Most Optimal Skills (High Demand + High Salary)

The analysis identifies skills that offer both strong market demand and competitive salaries:

* **Python** stands out with the highest demand among premium-paying skills, making it one of the best investments for aspiring data analysts.
* **Tableau, SQL Server, Azure, AWS, Snowflake, and Looker** provide an excellent balance of salary potential and employer demand.
* Specialized technologies such as **Go, Hadoop, and BigQuery** offer higher salaries but appear in fewer job postings, making them niche skills.

```sql
WITH skills_demand AS (
    SELECT 
    skills_dim.skill_id,
    skills_dim.skills,
    COUNT(skills_job_dim.job_id) AS demand_count
    FROM job_postings_fact
    INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
    INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
    WHERE  
        job_title_short = 'Data Analyst'
        AND salary_year_avg IS NOT NULL
        AND job_work_from_home = TRUE
    GROUP BY   
    skills_dim.skill_id
), average_salary AS (
    SELECT 
    skills_job_dim.skill_id,
    ROUND(AVG(salary_year_avg), 0) AS avg_salary
    FROM job_postings_fact
    INNER JOIN skills_job_dim ON job_postings_fact.job_id = skills_job_dim.job_id
    INNER JOIN skills_dim ON skills_job_dim.skill_id = skills_dim.skill_id
    WHERE  
        job_title_short = 'Data Analyst' 
        AND salary_year_avg IS NOT NULL
        AND job_work_from_home = TRUE
    GROUP BY   
    skills_job_dim.skill_id
)

SELECT 
    skills_demand.skill_id,
    skills_demand.skills,
    demand_count,
    avg_salary
FROM 
    skills_demand
INNER JOIN average_salary ON skills_demand.skill_id = average_salary.skill_id
WHERE
    demand_count>10
ORDER BY   
    avg_salary DESC,
    demand_count DESC
LIMIT 25;
```

**Insight:** Developing expertise in Python, SQL, Tableau, cloud platforms, and modern data warehouses provides the strongest combination of employability and earning potential.
